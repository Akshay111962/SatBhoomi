# Security & Privacy Checklist (Task T-13, Blueprint Section 10)

This checklist documents the security, privacy, and compliance controls implemented for **SatBhoomi Score + Raksha**, mapped directly to Section 10 of the Product Blueprint.

> [!IMPORTANT]
> **Legal Notice**: India's Digital Personal Data Protection (DPDP) Act, 2023 is likely relevant once real personal data is used (consent lifecycle, notice, purpose limitation, and right to erasure). This implementation represents a technical prototype aligning with DPDP principles; it is **not legal advice** and has **not been verified for this case** by legal counsel.
>
> **Synthetic Data Note**: The repository currently operates strictly on synthetic sample data points (`data_origin='synthetic'`). Creating real farmer records is disabled by default via `ALLOW_REAL_DATA=false`. No real farmer identities, government IDs (e.g. Aadhaar), PAN numbers, or bank account credentials are stored in this system.
