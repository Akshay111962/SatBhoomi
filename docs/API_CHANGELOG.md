# SatBhoomi API Contract Changelog

This document tracks all versioned changes to the **SatBhoomi Score + Raksha** REST API specification ([`docs/api/openapi.json`](file:///d:/SatBhoomi/docs/api/openapi.json)), implementing Blueprint Section 8.

---

## Governance Rules
1. **Semantic Versioning**:
   - `MAJOR`: Incompatible / breaking API changes (marked **[BREAKING]**).
   - `MINOR`: New backwards-compatible endpoints or optional parameters.
   - `PATCH`: Backwards-compatible schema bug fixes, documentation, and example refinements.
2. **Mandatory Version Bump**: Every modification to any route, schema, header, or error envelope in `src/satbhoomi/api/` requires bumping `API_CONTRACT_VERSION` in `src/satbhoomi/api/main.py`.
3. **Automated Drift Enforcement**: CI runs an automated drift test asserting that `docs/api/openapi.json` is identical to the spec generated by `scripts/export_openapi.py`.
4. **Deprecation Window**: Deprecated endpoints will be marked `deprecated: true` in OpenAPI and supported for at least one minor release cycle before removal.

---

## Releases

### [0.1.0] - 2026-11-13 (Initial Foundation & Mock Contract)
* **Initial API Contract Release**:
  - Implemented blueprint section 8 specification across 10 core endpoints:
    - `POST /api/v1/auth/login`: Officer authentication and session token issuance.
    - `POST /api/v1/plots`: Agricultural plot registration with area validation.
    - `GET /api/v1/plots`: Paginated plot listing with district filtering.
    - `POST /api/v1/plots/{id}/assessments`: Credit risk score evaluation with `Idempotency-Key` support.
    - `GET /api/v1/assessments/{id}`: Detailed risk score retrieval matching `RiskScoreResult` (T-06).
    - `POST /api/v1/assessments/{id}/what-if`: [DRAFT] What-if simulation engine projecting score sensitivity with mandatory `"estimate"` label and causation disclaimer.
    - `GET /api/v1/plots/{id}/monitoring`: [DRAFT] In-season vegetative timeline and active stress alerts.
    - `POST /api/v1/alerts/{id}/actions`: [DRAFT] Audited officer action logging.
    - `GET /api/v1/plots/{id}/relief-report`: [DRAFT] RBI 33% calamity relief evidence report with mandatory disclaimer.
    - `GET /api/v1/assessments/{id}/farmer-summary`: [DRAFT] Vernacular summaries in English, Gujarati, and Hindi with template source provenance.
  - Implemented standard error response body: `{"error": {"code", "message", "field"}}`.
  - Added configurable CORS via `CORS_ALLOWED_ORIGINS` (defaults: `http://localhost:5173`, `http://localhost:3000`).
  - Added synthetic mock server engine activated via `MOCK_API=true` (refuses to start when `ENVIRONMENT=production`).
  - When `MOCK_API=false` (default), all business endpoints return HTTP `501 Not Implemented`.
  - Standard system `/health` route remains active across all configurations.
